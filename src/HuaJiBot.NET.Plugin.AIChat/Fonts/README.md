ANSI Shadow.flf is the FIGlet font used by TAAG. It was sourced from the
[Figgle repository](https://github.com/drewnoakes/figgle/blob/master/tests/Figgle.Generator.Tests/ANSI%20Shadow.flf).
The font header lists its author as unknown and links to the
[FIGFont editor](https://patorjk.com/figfont-editor/). Figgle's repository is
distributed under the Apache 2.0 license. The bot uses Figgle 0.6.6 to parse
and render this font at runtime.
